# Precios de Sobrevive

Precios de supermercados de Venezuela (Excelsior Gama, Río Supermarket, Automercados Luvebras y El Páramo) y la tasa BCV del día. Se actualizan solos todos los días a las 6:00 de Venezuela.

- `manifiesto.json`: la fecha, la tasa y el estado de cada cadena.
- `catalogos/<cadena>.json`: los productos de cada cadena, con su precio en $ y Bs.

Los precios se leen de las tiendas en línea públicas de cada cadena. Pueden tener diferencias con el precio en la tienda física.
